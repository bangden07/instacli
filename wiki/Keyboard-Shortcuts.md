# Keyboard Shortcuts

Master the InstaCli TUI with these keyboard shortcuts.

## 🎯 Global Shortcuts

| Key | Action | Available In |
| --- | ------ | ------------ |
| `q` | Quit application | All views |
| `?` | Show help | All views |
| `Esc` | Go back / Cancel | All views |
| `Tab` | Toggle Local/SSH mode | Main menu |

## 📋 Navigation

| Key | Action |
| --- | ------ |
| `↑` or `k` | Move cursor up |
| `↓` or `j` | Move cursor down |
| `Enter` | Select current item |
| `Esc` or `Backspace` | Go back to previous view |

## 🔧 Installer Actions

| Key | Action | Description |
| --- | ------ | ----------- |
| `i` | Install | Run the installer immediately |
| `g` | Generate | Generate script without running |

## ⚙️ Settings

| Key | Action |
| --- | ------ |
| `e` | Enter edit mode |
| `Tab` | Next input field |
| `Shift+Tab` | Previous input field |
| `Enter` | Save and exit edit mode |
| `Esc` | Cancel editing |

## 📥 Clone & Setup

| Key | Action |
| --- | ------ |
| `Enter` | Start clone and setup |
| `Esc` | Cancel and go back |
| `Ctrl+V` | Paste URL (terminal dependent) |

## 💡 Tips

### Vim-style Navigation
If you're a Vim user, you'll feel at home:
- `j` = Down
- `k` = Up

### Quick Access
- From main menu, press number keys to jump to categories (if supported by terminal)

### Tab Completion
- In Clone & Setup view, the URL field supports paste from clipboard
